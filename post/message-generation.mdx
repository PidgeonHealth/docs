title: Message Generation
description: Generate HL7, FHIR, and NCPDP test messages in seconds. No manual creation, no production data copying, no compliance risk.

Every code comes from a real reference dataset (ICD-10, LOINC, NDC, SNOMED CT, CVX, RxNorm, HCPCS), so generated messages pass downstream validation the same way production data would.

## Supported Standards

<CodeGroup>
```bash HL7 v2
pidgeon generate ADT^A01 --count 5
pidgeon generate ORU^R01 --count 3
pidgeon generate ORM^O01
```

```bash FHIR R4
pidgeon generate Patient --count 5
pidgeon generate Observation
pidgeon generate Bundle
```

```bash NCPDP SCRIPT
# NCPDP is license-gated (see below)
pidgeon generate NewRx
pidgeon generate RxFill
pidgeon generate CancelRx
```
</CodeGroup>

<Note>HL7 v2 and FHIR R4 generation are free. NCPDP SCRIPT generation is **closed by default**: it requires confirming NCPDP membership and installing the licensed standards package (`pidgeon data install ncpdp-script --accept-license`). Until then the CLI and apps report NCPDP as license-required rather than emitting a message.</Note>

## NCPDP SCRIPT 2017071

<Warning>NCPDP SCRIPT generation is **closed by default** and license-gated. NCPDP's SCRIPT XSDs are member-only, so the standards material is not shipped: confirm your NCPDP membership, then run `pidgeon data install ncpdp-script --accept-license` to install the package. ## Generation Modes

<AccordionGroup>
  <Accordion title="Procedural (Free)" icon="gear">
    Deterministic generation using reference datasets (ICD-10, LOINC, NDC, SNOMED). Fast and reproducible. Available to all users.

    ```bash
    pidgeon generate ADT^A01 --mode procedural
    ```
  </Accordion>

  <Accordion title="On-device model (Pro)" icon="microchip">
    Uses a local AI model for clinical narratives and free-text note content. On-device by default, so no message content leaves the machine.

    ```bash
    pidgeon generate ORU^R01 --mode model
    ```
  </Accordion>

  <Accordion title="Cloud API (Pro)" icon="cloud">
    Routes narrative generation to a configured cloud provider (BYOK). Off-device inference requires an explicit opt-in.

    ```bash
    pidgeon generate MDM^T02 --mode api
    ```
  </Accordion>
</AccordionGroup>

## Reproducibility

Use `--seed` for deterministic output. The same seed always produces the same message, making tests repeatable across machines and CI runs:

```bash
# Same seed = identical output every time
pidgeon generate ADT^A01 --seed 42

# With --count, every message uses the same seed (identical copies)
pidgeon generate ADT^A01 --count 10 --seed 42
```

## Output Options

```bash
# Write to a file
pidgeon generate ADT^A01 --output ./messages/admit.hl7

# JSON format for FHIR
pidgeon generate Patient --format json

# NDJSON for bulk loading
pidgeon generate Observation --count 100 --format ndjson
```

# Pidgeon documentation

The source for the public Pidgeon documentation site. It covers the community engine, the
CLI, and the MCP server: getting started, command and tool references, and how-to guides for
generating, validating, and de-identifying HL7 v2, FHIR R4, and NCPDP messages with synthetic
data.

This repository is a public release mirror, published from an upstream development source.

## Local preview

The site is built with [Mintlify](https://mintlify.com). Requires Node.js 22 LTS.

```bash
npm install
npm run dev
```

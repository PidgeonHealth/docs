<Note>Loft is a Pro product delivered with the Loft desktop app. The `pidgeon loft` commands and the local Bridge on `localhost:5100` ship with that app. The free `dotnet tool install --global Pidgeon.CLI` build does not include `loft`.</Note>

## pidgeon loft watch

Watch a directory for incoming `.hl7` files and validate each one as it lands.

```bash
pidgeon loft watch --path <path> [options]
```

| Flag | Type | Default | Description |
|------|------|---------|-------------|
| `--path <path>` | string | Required | Directory to watch for `.hl7` files |
| `--profile <name>` | string | none | Vendor profile for validation |
| `--mode <mode>` | string | `compatibility` | Validation mode: `strict` or `compatibility` |
| `--alert <spec>` | string | `console` | Alert provider: `console`, `file:<path>`, or `webhook:<url>`. Repeatable. |

```bash
# Watch a Mirth output directory against a vendor profile
pidgeon loft watch --path /var/mirth/outbound/er --profile epic_er

# Watch in strict mode and post failures to a webhook
pidgeon loft watch --path /var/loft/lab --mode strict --alert webhook:https://hooks.example.org/loft
```

The `watch` command validates `.hl7` files only, and its `--alert` flag covers the console, file, and webhook providers inline. To watch a custom file pattern, or to route to Slack, Microsoft Teams, email, or PagerDuty, create a persistent interface through the desktop app or its local Bridge. See [Interface Monitoring](/loft/interface-monitoring) and [Alerting](/loft/alerting).

## pidgeon loft status

Show current monitoring metrics across all watched interfaces.

```bash
pidgeon loft status
```

## pidgeon loft alerts

List recent alerts from the Loft metrics store.

```bash
pidgeon loft alerts [options]
```

| Flag | Type | Default | Description |
|------|------|---------|-------------|
| `--since <duration>` | string | `1h` | Time window (e.g. `1h`, `12h`, `7d`) |
| `--severity <level>` | string | All | Filter: `critical`, `warning`, `info`, `error` |
| `--format <fmt>` | string | `table` | Output format: `table` or `json` |
| `-o, --output <path>` | string | stdout | File path for the JSON export |

```bash
# Critical alerts from the last 6 hours
pidgeon loft alerts --severity critical --since 6h

# All recent alerts as JSON
pidgeon loft alerts --since 1h --format json
```

## pidgeon loft report

Generate a summary report of Loft monitoring activity.

```bash
pidgeon loft report [options]
```

| Flag | Type | Default | Description |
|------|------|---------|-------------|
| `--since <duration>` | string | `24h` | Time range for the report |
| `--format <fmt>` | string | `text` | `text`, `json`, `pdf`, `excel`, or `html` |

Text and JSON print to stdout. For a PDF, Excel, or HTML file, use `pidgeon loft report generate`, which writes to a path with `-o`:

```bash
# Text report for the last 24 hours
pidgeon loft report

# HTML report file for the last week
pidgeon loft report generate --format html --since 7d --output report.html
```

`report generate` also takes `--template` (`interface-health`, `partner-scorecard`, or `sla-compliance`). The `report schedule`, `report list`, `report run`, and `report history` subcommands manage recurring reports.
